# Third-party notices

## PIA's CA certificate

`ca.rsa.4096.crt` is Private Internet Access's public CA certificate, as
published in PIA's manual-connections repository
(https://github.com/pia-foss/manual-connections) and in PIA's OpenVPN
configuration bundle; the two copies are identical (SHA-256
`32e9b1d1433ea97614f2a14c6e358e3f57c0570cc9f6b2ee812699ba696c66ab`). It is
included unmodified so that it never has to be downloaded at connect time.
